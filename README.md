## 🎨 Design Philosophy — "LiquidGL & Chromatic Ether"

The UI architecture departs from standard web templates by implementing a dynamic **Liquid Glass** physical material simulation:

* **Real-time 3D WebGL Caustics**: Centerpiece floating crystal slab powered by `@react-three/fiber` and `@react-three/drei` (`MeshTransmissionMaterial`), featuring internal chromatic dispersion, sub-surface scattering, and cursor-driven parallax tilt.
* **Apple & VisionOS Frosted Glass Sheet**: Multi-layer frosted glass cards with `backdrop-filter: blur(40px) saturate(200%)` and 1px specular top-edge reflections.
* **Eye-Friendly Deep Obsidian Palette**: Calibrated `#060812` background base accented by Electric Cyan (`#00F0FF`), Royal Indigo (`#6366F1`), and Twilight Violet (`#8B5CF6`).
* **Micro UX Interactions**: Magnetic button spring physics, top scroll progress indicator, and a smart dual Resume/CV dropdown.

## 🚀 Getting Started

### Prerequisites
* **Node.js**: `v18.0.0` or higher
* **npm**: `v9.0.0` or higher

### Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vishal-baruah/vishal-baruah.github.io.git
   cd vishal-baruah.github.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for Production**:
   ```bash
   npm run build
   ```
